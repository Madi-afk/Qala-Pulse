# Синтетические материалы

Seed создаёт 28 собственных геометрических рисунков с надписью `SYNTHETIC DEMO`, без фотографий людей и внешних лицензий. Рисунки выпущены под MIT вместе с проектом. Они предназначены для проверки загрузки и не являются доказательствами реальных проблем.

Для ручного выбора из галереи выполните из корня:

```bash
python scripts/create_samples.py
```

Файлы появятся в `sample_data/images/`. Для проверки mock-анализа используйте описание «яма на дороге», «открытый люк», «мусор», «не работает фонарь». Mock классифицирует текст и не распознаёт содержание рисунка.

Внешние реальные изображения добавляйте только с понятными правами и согласием, исключив персональные данные. Не коммитьте фотографии участников пилота.

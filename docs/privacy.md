# Приватность MVP

Для пилота реализована [политика сроков хранения и удаления файлов](photo-retention.md): оригиналы 7 дней, аудио 2 дня, неприкреплённые фото 7 дней, публичные версии 90 дней. Оператор должен включить задачу очистки и утвердить правила до приглашения жителей.

## Собираемые данные

- Email, имя, необязательный телефон, предпочтительный язык — учётная запись и общение в пилоте. Пароль хранится только как Argon2id-хеш.
- Фото, выбранная точка, текст и аудио — описание городской проблемы. GPS запрашивается по действию пользователя; постоянного фонового отслеживания нет.
- Подтверждения, комментарии, жалобы и журнал действий — качество данных и модерация.
- Случайный request ID и техническая статистика — диагностика. Тела запросов, email, токены, аудио, фотографии и транскрипты в технические логи не записываются.

## Публичная поверхность

Лента публикует координаты проблемы, текст, статус, счётчики, обезличенный UUID автора и обработанное фото. Комментарий содержит отображаемое имя автора. Email, телефон, оригинал фото и аудио публично не выдаются. Поэтому пользователь должен указывать место проблемы, а не домашний адрес, если это не требуется, и не включать личные данные в текст.

Оригиналы и redacted-версии находятся в **разных закрытых** MinIO-бакетах. Выдача публичного изображения идёт через API с проверкой доступности Incident. Скрытие обращения закрывает последующие запросы к фото. Уже скачанный чужим клиентом материал нельзя гарантированно отозвать.

## Обработка изображений

По умолчанию `PRIVACY_MODE=local`: OpenCV локально ищет лица и автомобильные номера. Найденные области с запасом мозаицируются и размываются; остальной кадр сохраняет детали с учётом уменьшения до 1600 px и JPEG-сжатия. EXIF и другие исходные метаданные удаляются. Обработка приватности не отправляет изображение в облако и не зависит от `AI_MODE`.

При ошибке детектора весь кадр автоматически мозаицируется. Такой же результат можно выбрать через `PRIVACY_MODE=full_frame` или кнопку «Размыть фото целиком» в приложении. Перед публикацией пользователь загружает обработанный предпросмотр, может увеличить его и обязан подтвердить проверку изображения и текста. Ошибка повторной обработки сохраняет черновик и снимает прежнее подтверждение проверки.

**Детектор может пропустить лицо или номер. Отсутствие найденных областей не означает отсутствие персональных данных.** Базовый номерной каскад не обучен специально на номерах Казахстана; добавлен геометрический поиск светлых табличек с тёмными символами. Документы, бейджи, надписи, отражения и другие чувствительные объекты надёжно не определяются. Сертифицированная анонимизация не заявляется. Если в предпросмотре остались личные данные, используйте полное размытие либо другое фото.

Контрольные снимки, результаты и условия расширенной проверки описаны в [обработке фотографий](photo-privacy.md). До использования реальных данных нужна проверка на репрезентативных постановочных снимках. Ранее загруженные изображения автоматически не перерабатываются.

## Cloud AI

При AI_MODE=mock изображения не отправляются внешнему AI. В cloud нужны конфигурация провайдера и согласие в мобильном flow. После согласия провайдер получает преобразованное фото без EXIF, текст и/или аудио. Для embeddings передаётся текст поиска и кандидатов. Место хранения, сроки retention и договор с провайдером определяет оператор; MVP не может обещать локальное хранение при внешнем API.

Не используйте cloud для персональных данных до проверки договора, юрисдикции и условий обработки. В пилоте рекомендуется mock или локальный совместимый endpoint. Указанное предупреждение — операционное ограничение проекта, а не заключение о соответствии законодательству.

## Локальное устройство

Access/refresh — `flutter_secure_storage`. Черновик, координаты и описание — SharedPreferences; фотография/аудио — каталог документов приложения. Черновик разделён по пользователю. Android backup отключён. Удаление приложения удаляет локальные данные согласно политике ОС. Браузерная версия предназначена для демонстрации; аппаратное защищённое хранилище мобильной ОС к ней не относится.

## Сроки и удаление

Очистка оригиналов, аудио, публичных и сиротских файлов реализована в `app.retention`; расписание включается при развёртывании. Досрочное удаление конкретной загрузки доступно через `--erase-upload`. Сроки, dry-run, backup и журнал удаления описаны в [политике файлов](photo-retention.md). Автоматическое удаление аккаунтов и обезличивание всех связанных текстовых записей пока не реализованы. Их обрабатывает оператор отдельно с проверкой зависимостей и минимальным аудитом; массовый SQL DELETE без проверки не применять.

Процедура [восстановления](pilot-deployment.md) включает отзыв сессий, повторную очистку и применение журнала досрочных удалений. До пилота назначить контакт поддержки и утвердить процедуру экспорта данных и обработки инцидентов. Demo-данные не смешивать с персональными данными жителей.

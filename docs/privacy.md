# Приватность MVP

## Собираемые данные

- Email, имя, необязательный телефон, предпочтительный язык — учётная запись и общение в пилоте. Пароль хранится только как Argon2id-хеш.
- Фото, выбранная точка, текст и аудио — описание городской проблемы. GPS запрашивается по действию пользователя; постоянного фонового отслеживания нет.
- Подтверждения, комментарии, жалобы и журнал действий — качество данных и модерация.
- Случайный request ID и техническая статистика — диагностика. Тела запросов, email, токены, аудио, фотографии и транскрипты в технические логи не записываются.

## Публичная поверхность

Лента публикует координаты проблемы, текст, статус, счётчики, обезличенный UUID автора и обработанное фото. Комментарий содержит отображаемое имя автора. Email, телефон, оригинал фото и аудио публично не выдаются. Поэтому пользователь должен указывать место проблемы, а не домашний адрес, если это не требуется, и не включать личные данные в текст.

Оригиналы и redacted-версии находятся в **разных закрытых** MinIO-бакетах. Выдача публичного изображения идёт через API с проверкой доступности Incident. Скрытие обращения закрывает последующие запросы к фото. Уже скачанный чужим клиентом материал нельзя гарантированно отозвать.

## Обработка изображений

По умолчанию работает консервативный mock-redactor: весь кадр сводится к сетке 12×12, увеличивается и размывается, EXIF удаляется. Это демонстрирует безопасный путь хранения/публикации и сильно снижает детализацию. **Это не сертифицированная анонимизация и не качественная детекция лиц/номеров.** Не используйте тестовый контур для чувствительных материалов. Распознавание номеров и чувствительных объектов не заявляется готовым. Оператор пилота должен визуально проверять публичный результат.

## Cloud AI

При AI_MODE=mock изображения не отправляются внешнему AI. В cloud нужны конфигурация провайдера и согласие в мобильном flow. После согласия провайдер получает преобразованное фото без EXIF, текст и/или аудио. Для embeddings передаётся текст поиска и кандидатов. Место хранения, сроки retention и договор с провайдером определяет оператор; MVP не может обещать локальное хранение при внешнем API.

Не используйте cloud для персональных данных до проверки договора, юрисдикции и условий обработки. В пилоте рекомендуется mock или локальный совместимый endpoint. Указанное предупреждение — операционное ограничение проекта, а не заключение о соответствии законодательству.

## Локальное устройство

Access/refresh — `flutter_secure_storage`. Черновик, координаты и описание — SharedPreferences; фотография/аудио — каталог документов приложения. Черновик разделён по пользователю. Android backup отключён. Удаление приложения удаляет локальные данные согласно политике ОС. Браузерная версия предназначена для демонстрации; аппаратное защищённое хранилище мобильной ОС к ней не относится.

## Сроки и удаление

Автоматическое удаление аккаунтов, сиротских загрузок и старых оригиналов пока не реализовано. До пилота оператор назначает контакт для запросов, фиксирует сроки хранения и резервного копирования. Процедура удаления: удостоверить заявителя; закрыть связанные публичные материалы; удалить объекты по ключам Upload/IncidentMedia; удалить/обезличить связанные записи и сессии с сохранением минимального аудита; учесть срок истечения резервных копий. Не выполнять массовый SQL DELETE без предварительного dry-run и проверки зависимостей.

Нужны отдельные процедуры восстановления, экспорта, обработки инцидентов безопасности и контроля доступа операторов. На запуске с demo-данными реальных персональных данных быть не должно.
